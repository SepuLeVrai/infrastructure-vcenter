Infrastructure vCenter s'installe depuis un dépôt personnalisé dans le Marketplace Home Assistant ou HACS. L'archive de l'intégration inclut la carte JavaScript.

Pour reprendre une installation manuelle, sauvegarder Home Assistant, conserver l'entrée VMware et la vue existantes, télécharger 0.4.1, puis redémarrer. La ressource JavaScript existante est actualisée si elle est gérée dans l'interface. Les ressources déclarées en YAML nécessitent une mise à jour de leur URL. [Guide HAOS et migration](https://github.com/SepuLeVrai/infrastructure-vcenter/blob/0.4.1/docs/INSTALLATION.md).

Home Assistant Core 2026.6 ou ultérieur.

- `infra_vcenter.zip` pour le Marketplace et HACS.
- `infrastructure-vcenter-0.4.1.zip` pour une installation manuelle par Samba.
- Archives séparées pour la carte et le collecteur MQTT.
- `SHA256SUMS` pour vérifier les fichiers téléchargés.
